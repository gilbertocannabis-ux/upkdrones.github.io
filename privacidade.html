Política de Privacidade

Última atualização: 15 de novembro de 2026

Esta política explica como a ferramenta "Upk Drones - Cortes" trata dados, conforme a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018).

1. Dados que acessamos

Com a autorização do usuário, a Ferramenta recebe do TikTok: informações básicas do perfil (identificador e nome de exibição) e um token de acesso que permite enviar vídeos para a conta autorizada.

2. Para que usamos

Os dados são usados exclusivamente para enviar os vídeos que o próprio usuário escolheu para a conta dele no TikTok. Não usamos os dados para publicidade nem para criar perfis.

3. Armazenamento

O token de acesso fica salvo apenas no computador do usuário onde a Ferramenta é executada. Não mantemos servidores com dados de usuários e não vendemos nem compartilhamos dados com terceiros.

4. Seus direitos

O usuário pode revogar o acesso a qualquer momento no TikTok (Configurações → Segurança → Apps conectados) e apagar os dados locais excluindo a pasta "dados" da Ferramenta. Pedidos relacionados à LGPD podem ser feitos pelo contato abaixo.
